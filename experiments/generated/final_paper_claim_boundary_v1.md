## 2. 论文可以主张的结论

### 2.1 主实验结论

可以写：

在冻结的CTP100智慧旅游任务集上，自适应多Agent方法M3取得最高任务成功率。四种方法的STSR分别为：

| 方法 | STSR |
| --- | ---: |
| M0 直接大模型 | 0.08 |
| M1 单Agent工具型 | 0.41 |
| M2 固定多Agent | 0.86 |
| M3 自适应多Agent | 0.96 |

M3相对M2的STSR提升为10个百分点，95%置信区间为[4, 17]个百分点，McNemar检验p=0.0063。

推荐论文表述：

> 在CTP100主实验中，M3相对M2在任务成功率上取得10个百分点提升，配对检验显示该差异具有统计证据支持。这表明面向旅游任务的状态驱动自适应多Agent调度，相比固定多Agent链路具有更好的任务完成能力。

### 2.2 重复稳定性结论

可以写：

在CTP100的M2/M3三次重复实验中，M3仍保持稳定优势：

| 方法 | 三次重复平均STSR |
| --- | ---: |
| M2 固定多Agent | 0.8567 |
| M3 自适应多Agent | 0.9567 |

M3相对M2的平均提升仍为10个百分点，95%置信区间为[4, 16.67]个百分点，McNemar检验p=0.002。

推荐论文表述：

> 为降低单次大模型输出波动对结论的影响，本文对M2和M3进行了三次重复实验。结果显示，M3在三次重复中均保持约10个百分点的STSR优势，说明主实验观察到的性能提升具有重复稳定性证据。

### 2.3 结果复用消融结论

可以写：

在CTP100中全部30个双轮场景的目标轮上，M3-full和M3-no-reuse的STSR相同，均为0.9667；但M3-full显著降低资源开销。

| 指标 | M3-full | M3-no-reuse | M3-full - M3-no-reuse |
| --- | ---: | ---: | ---: |
| STSR | 0.9667 | 0.9667 | 0.0000 |
| Agent F1 | 1.0000 | 0.7121 | +0.2879 |
| Tool F1 | 1.0000 | 0.6656 | +0.3344 |
| 平均Token | 12942.6000 | 17728.2556 | -4785.6556 |
| 标准化估算成本 | 0.0083 | 0.0126 | -0.0044 |
| 平均时延ms | 32479.5783 | 62018.0020 | -29538.4237 |

| Agent调用数 | 2.1667 | 3.7333 | -1.5667 |
| Tool调用数 | 1.4000 | 2.7333 | -1.3333 |

推荐论文表述：

> 消融实验表明，在双轮任务目标轮上，结果复用并未进一步提高STSR，但明显减少了重复Agent调用、工具调用、Token消耗、标准化估算成本和响应时延。因此，M3中的结果复用机制主要体现为资源效率收益，而不是任务成功率收益。

### 2.4 二级指标统计结论

可以写：

Holm多重比较校正后，M3相对M2在主实验中的Token消耗和标准化估算成本差异具有统计显著性；时延差异在校正后不显著。

必须注意方向：

- M3相对M2的平均Token更高：M2为6131.58，M3为7901.51。
- M3相对M2的标准化估算成本更高：M2为0.0049，M3为0.0055。
- 因此不能写“M3比M2更省Token/成本”。

推荐论文表述：

> M3通过更完整的状态建模和自适应调度获得更高任务成功率，但也带来更高Token消耗和标准化估算成本。这说明本文方法在效果与资源开销之间存在可量化权衡。

### 2.5 封闭验证与局限性结论

可以写：

CTP30-v1和CTP30-v2应作为封闭验证与边界分析。尤其是CTP30-v2中，M2与M3的STSR均为0.6333，差值为0，McNemar检验p=1.0。

推荐论文表述：

> 在更严格的CTP30-v2封闭多轮验证中，M3没有表现出相对M2的显著优势。这表明当前方法在未见自然表达和真实多轮状态传递场景下仍存在泛化边界，后续需要进一步改进任务识别、上下文状态更新和跨轮调度鲁棒性。

## 3. 论文不能主张的结论

以下表述不能写，或者只能作为非常谨慎的推测：

| 不能写的说法 | 原因 |
| --- | --- |
| M3在所有旅游场景中都优于M2 | 证据只覆盖冻结的CTP100和CTP30验证集 |
| M3在CTP30-v2封闭多轮验证中优于M2 | CTP30-v2中二者STSR相同，p=1.0 |
| 结果复用提升了任务成功率 | 消融实验显示M3-full和M3-no-reuse的目标轮STSR相同 |
| M3比M2更省Token或成本 | 主实验中M3相对M2的Token和标准化估算成本更高 |
| 系统使用实时天气完成正式实验 | 正式实验使用冻结天气快照，不是实时在线天气 |
| 标准化估算成本等于中转API真实账单 | 成本是按冻结价格规则计算的标准化估算值 |
| 标注由多人独立完成并计算一致性 | 当前是单人标注加自动规则审计，不能写成多人一致性标注 |
| CTP30-v1/v2失败结果是文件损坏或无效结果 | 它们是封闭验证暴露出的真实性能边界，应保留并讨论 |

## 4. 论文建议组织方式

建议把实验部分组织为四层，不要混在一张结论里：

1. CTP100主实验：回答“多Agent和自适应调度是否有效”。
2. M2/M3重复稳定性：回答“主实验优势是否只是单次模型波动”。
3. M3-no-reuse消融：回答“结果复用到底带来什么作用”。
4. CTP30-v1/v2封闭验证：回答“方法在更严格未见多轮场景下的边界在哪里”。

这种写法的优点是：主结论有正向结果，补充实验说明稳定性，消融实验解释机制，封闭验证主动披露局限性。

## 5. 最终可写入论文的核心结论

建议论文最终只坚持以下三条强结论：

1. 在冻结CTP100任务集上，M3相对M2取得稳定的任务成功率提升。
2. M3的优势主要来自状态驱动的自适应多Agent调度链路，而结果复用主要带来资源效率收益。
3. 在更严格的CTP30-v2封闭多轮验证中，M3优势不明显，说明系统仍存在多轮泛化和鲁棒性边界。

这三条结论有完整实验数据支撑，适合用于中文学术论文的摘要、实验结论和局限性部分。
